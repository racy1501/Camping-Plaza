# ⛺ 露营广场 Camping Plaza

一个主要由 AI 通过 MCP 自主经营、人类也可以通过网页查看和操作的露营经营游戏。

## 项目简介

在《露营广场》中，你需要把一片露营地经营起来：接待日间客人和过夜客人，安排帐篷、营位、餐饮、娱乐与绿化，处理每天的客流和经营结果，并逐步建设更完整的营地。

游戏的主要经营者是通过 MCP 接入的 AI。AI 读取游戏状态后决定经营动作，游戏代码负责检查规则、容量、库存和资金，并执行收费、结算和状态更新。人类可以通过网页查看同一座营地的经营过程，也可以进行网页支持的操作。

## 核心玩法

- 接待日间客人和过夜客人，管理营位与帐篷容量。
- 经营餐饮、娱乐和绿化，平衡收入、库存、费用与营地评价。
- 根据客流、设施状态和当天进展安排经营决策。
- 通过成长项目逐步扩展营地设施。
- 观察 NPC 的到达、消费、活动、离场和评价。
- 以建成最终设施“温泉”为 v1 的明确目标；建成后仍可继续经营营地。

每天的客流和可执行计划由游戏规则生成，AI 负责做决定，代码负责裁决结果。这样 AI 不需要自行猜测客流、收费、容量或设施状态。

## AI / MCP 如何游玩

AI 的基本经营流程是：

```text
读取状态 → 查看可用操作 → 提交经营决策 → 推进回合 → 读取结果
```

游戏提供面向 MCP 封装层使用的 HTTP 接口，主要包括：

- `/mcp/state`：读取 AI 决策所需的精简状态。
- `/mcp/actions`：读取当前可执行的操作和参数。
- 游戏 API：创建 session、设置经营者名称、提交回合计划、推进日期和执行经营动作。

本仓库提供的是游戏后端和适合外部 MCP 封装调用的接口，不是原生 MCP 协议服务器。完整的接口、参数、session 和调用顺序请参阅 [`camping_plaza/README.md`](camping_plaza/README.md)。

## 人类网页如何使用

启动游戏服务后，可以直接通过浏览器打开网页入口，查看营地地图、客人、设施、经营状态、事件和评价。

人类网页与 AI 入口读取同一份游戏状态。网页主要用于围观和查看，也提供当前版本支持的人类操作；游戏规则、资源检查和结算仍由后端代码处理。

**人类网页入口：** <https://camping-plaza.onrender.com/>

直接打开即可创建自己的独立营地存档；如果 AI 使用同一个 `session_id`，也可以访问同一座营地。


## 本地运行

```bash
cd camping_plaza
pip install -r requirements.txt
python game_api.py
```

启动后访问：

- 网页入口：<http://localhost:8000/>
- API 文档：<http://localhost:8000/docs>

未配置 `DATABASE_URL` 时，项目使用本地 SQLite；其他 session、存档和部署配置请参阅 [`camping_plaza/README.md`](camping_plaza/README.md)。
